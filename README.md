# LinkedIn-Themed-Sales-Dashboard-Power-BI-

An interactive Power BI dashboard built on the Superstore sales dataset, styled as a LinkedIn-profile portfolio page. 


## Features
- KPI cards: Mail, Followers, Target
- Ribbon chart: sales by category (Office Supplies, Furniture, Technology)
- Filled map: US states by sub-category
- Field-selector slicer: Order ID, Order Date, Customer Name
- Pie chart: 2019 vs 2020 comparison
- Funnel and treemap: payment mode split (COD, Online, Cards)
- Combo chart: Sum of Profit vs Count of Returns by Quantity
- Navigation buttons and a "Clear all slicers" reset

## Tools
Power BI, DAX, Excel
